# SeqDatasets
This directory contains the datasets used for different EUGENe workflows.
## Jores et al. 2021 - Leaf system
This dataset contains the leaf system from Jores et al. 2021.
The data is loaded using the datasets module from EUGENe.
The dataset contains 72158 samples.
Each sequence is 170 nucleotides long.
The data is saved in the h5sd format.

## de Almeida et al. 2022 - Train set
This dataset contains the train set from de Almeida et al. 2022.
The data is loaded using the datasets module from EUGENe.
The dataset contains 402296 samples.
Each sequence is 249 nucleotides long.
The data is saved in the h5sd format.

## Kopp et al. 2021 - JUND train set
This dataset contains the JUND train set from Kopp et al. 2021.
The dataset was preprocessed as described in the EUGENe paper.
The dataset contains 948771 samples.
Each sequence is 500 nucleotides long.
The data is saved in the h5sd format.
